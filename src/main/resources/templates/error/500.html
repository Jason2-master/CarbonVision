서버 내부 오류가 발생했습니다 (Internal Server Error)

요청은 서버에 정상적으로 도착했으나, 백엔드(Java·DB) 처리 또는 화면(Thymeleaf) 렌더링 도중 예외가 발생했습니다.

요청 경로: /error
발생 시각: -
에러 메시지:
어디를 확인하면 좋을까요? (유력한 순서)
  1. IDE 콘솔의 빨간색 로그 (Caused by:) 확인: 가장 먼저 콘솔을 열고 아래쪽 Caused by 문구와 내 패키지(Controller·Service)가 찍힌 파일명·줄 번호를 확인
  2. MyBatis Mapper XML 및 Oracle SQL 확인: 쿼리 끝 세미콜론(;) 혼입, Mapper namespace·id 불일치(BindingException), 컬럼명 오타(ORA-00904), NULL 파라미터 바인딩 확인
  3. Java 로직 및 NullPointerException 확인: DB 조회 결과가 null인데 메서드를 호출했거나, @RequestParam 이름 누락·불일치 및 타입 변환 오류 확인
  4. Thymeleaf 문법 및 DTO Getter 확인: th: 표현식 오타, ${객체.필드명}에 해당하는 Getter 누락, 또는 null 객체의 속성에 접근했는지 확인
